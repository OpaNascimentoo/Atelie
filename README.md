# 🧵 Ateliê  — Sistema de Gestão de Pedidos (Em desenvolvimento)

Interface web para gerenciamento de pedidos de um ateliê de costura. Desenvolvida como uma aplicação de página única (SPA), com visual elegante inspirado na alta costura.

---

## ✨ Funcionalidades

- **Tela de Login** com validação de campos e toggle de senha
- **Painel de pedidos** com 4 seções agrupadas por status
- **Cards detalhados** exibindo cliente, serviço, peça, data, horário e status
- **Busca em tempo real** por nome do cliente, tipo de serviço ou peça
- **Estatísticas rápidas** com contadores por status
- **Modal de detalhes** ao clicar em cada pedido
- **Navegação entre telas** com transição animada
- **Layout responsivo** — funciona em desktop, tablet e celular
